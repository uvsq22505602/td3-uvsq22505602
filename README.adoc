# Java DNS Simulator (CLI)

Un simulateur de système de noms de domaine (DNS) en ligne de commande, développé en Java 17. Cette application agit comme un serveur DNS local, capable de résoudre des adresses IP en noms de domaine qualifiés (FQDN) et inversement.

Le projet respecte scrupuleusement les principes de programmation orientée objet (POO) et implémente le **patron de conception Command (Command Design Pattern)** pour gérer les interactions utilisateur de manière modulaire.

## 🚀 Fonctionnalités

* **Résolution DNS directe :** Saisissez un nom de domaine qualifié (ex: `www.example.com`) pour récupérer son adresse IP associée.
* **Résolution DNS inverse :** Saisissez une adresse IP (ex: `192.168.0.1`) pour obtenir le nom de la machine correspondante.
* **Listing par domaine :** Utilisez la commande `ls [domaine]` pour afficher toutes les machines enregistrées dans un domaine spécifique, triées par nom de machine.
* **Tri par IP :** Utilisez la commande `ls -a [domaine]` pour afficher les machines triées séquentiellement par adresse IP.
* **Enregistrement dynamique :** Ajoutez de nouvelles entrées DNS directement via la CLI avec la commande `add [IP] [nom_machine]`, avec une gestion des erreurs pour éviter les doublons.
* **Persistance des données :** La base de données DNS est conservée dans un fichier texte local, garantissant que toutes les modifications persistent entre chaque session. Le chemin du fichier est géré via un fichier de propriétés (`.properties`).

## 🛠️ Architecture & Technologies

* **Langage :** Java 17
* **Outil de build :** Maven (Wrapper inclus)
* **Architecture :** Pattern Command (encapsulation des requêtes en objets), interface textuelle (TUI).
* **Tests :** JUnit 4 (Tests unitaires complets pour la logique métier).
* **Qualité de code :** Application automatique des règles de style *Google Java Style* via `maven-checkstyle-plugin` durant la phase de validation.
* **Bibliothèques standards :** Utilisation intensive du *Collections Framework* et de `java.nio.file.Files` pour une gestion efficace des entrées/sorties.

## 💻 Démarrage rapide

### Prérequis
* Java Development Kit (JDK) 17 ou supérieur.
* Maven (Optionnel, le wrapper Maven `./mvnw` est inclus).

### Compilation
Clonez le dépôt et utilisez le wrapper Maven pour compiler le projet et exécuter les validations Checkstyle :

```bash
git clone [https://github.com/nassim-siziani/Java-DNS-Simulator.git](https://github.com/nassim-siziani/Java-DNS-Simulator.git)
cd Java-DNS-Simulator
./mvnw clean compile
